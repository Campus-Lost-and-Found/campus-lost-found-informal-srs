# Campus Lost & Found Platform — Informal SRS

## Project Overview
The Campus Lost & Found Platform aims to provide a centralized way for university students and staff to report, search for, and recover lost belongings on campus.

## Objectives
- Make reporting lost and found items easier.
- Help users search for potentially matching items.
- Improve communication between people who lose and find belongings.
- Support privacy and secure item handover.

## Repository Purpose
This repository contains the informal Software Requirements Specification (SRS), requirements analysis, and project backlog.
